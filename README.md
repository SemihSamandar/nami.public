## Features

- **Switch models mid-conversation** without losing context.
- **Projects:** organise conversations into projects, each with its own files and instructions.
- **Incognito mode:** messages are deleted when the session ends.
- **Streaming chat** with abort support and live status updates while the model is thinking
  or researching.
- **Native structured outputs:** single- and multiple-choice questions from the model are
  rendered as native views, not plain text.
- **Sign in with Apple and Google**, in-app subscriptions and a credit system.
